# ¿Dónde se te va el dinero?

Calculadora gratuita para negocios de restauración: estima en qué partidas se pierde margen.

- Funciona 100 % en tu navegador: no envía ni guarda ningún dato.
- Los rangos son orientativos, no una auditoría. Contrasta siempre con tus propios números.
- Proyecto independiente, sin ánimo de lucro por ahora. Código abierto (MIT).

Uso: abre `index.html` en cualquier navegador.
